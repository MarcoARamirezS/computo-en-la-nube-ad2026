# MoneyCloud — Repositorio guía para estudiantes

**Modalidad:** construir el código copiando y pegando desde los Markdown. Este repositorio empieza sin `apps/` para que cada estudiante lo cree durante el laboratorio.

**Ruta:** [Preparación](docs/00-preparacion.md) → [Sesión 1](docs/sesiones/01-frontend.md) → [Sesión 2](docs/sesiones/02-api-firestore.md) → [Sesión 3](docs/sesiones/03-docker.md) → [Sesión 4](docs/sesiones/04-deploy.md).

Duración: 4 × 90 minutos. Se recomienda instalar Docker y abrir cuentas antes de clase. La app es una demo con datos ficticios; no incluye cuentas de usuario ni protección para escritura pública.

**Para docentes:** la sesión 1 incluye una API de apoyo en memoria porque el frontend consume endpoints desde el inicio. La sesión 2 profundiza en la API y habilita Firestore. No se requiere descargar ningún ZIP de código para completar los laboratorios.
